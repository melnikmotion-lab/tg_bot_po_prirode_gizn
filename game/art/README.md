# Арт

- `source/` — оригиналы из ChatGPT (сцена пещеры, гоблин, портрет Брана, лист иконок).
- `pixel/` — то же после `tools/pixelize.py`, в палитре игры:
  - сцены: `--size 320x180`;
  - враги: `--size 80x80 --sprite --dark 0.82 --spread 6`;
  - портреты: `--size 96x96 --colors 32`;
  - иконки: `--size 32x32 --colors 16 --sprite`.
- `mock/` — макет экрана на телефоне (`mock.html`, `mock_bag.html`; картинки берёт из `pixel/` после копирования рядом).

Стиль: сцены — живописный пиксель-арт Amiga/DOS (детальный промпт), враги — крупные пиксели и простой силуэт, герои — портрет по грудь на чёрном фоне.
